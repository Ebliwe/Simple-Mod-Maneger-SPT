# Simple Mod Manager for SPT

A simple Windows application for managing mods in **Single Player Tarkov (SPT) 4.0.13**.

The goal of this project is to make finding, downloading, and installing SPT mods easier.

## Features

- Browse mods from The Forge.
- Find mods compatible with SPT 4.0.13.
- Check compatible mod versions.
- Install mods directly from the application.
- Support for ZIP, RAR, and 7Z archives.
- Create backups before modifying game files.

## Requirements

- Windows 10 or Windows 11 (64-bit).
- SPT 4.0.13.
- Internet connection for browsing and downloading mods.

## Installation

1. Open the [Releases](../../releases) page.
2. Download the latest release.
3. Extract the downloaded archive, if necessary.
4. Run `SPT Mod Manager.exe`.
5. Select your SPT installation folder.

*If no release is available yet, check back later.*
